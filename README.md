# AI Email Summarizer - Frontend Dashboard

This is a modern React-based dashboard that displays email summaries generated by AI. It allows users to view, trigger, and manage their email data in real-time.

##  Setup & Installation

1. **Install Dependencies:**
   ```bash
   npm install

2. **Configure Backend URL:**
    Ensure your Backend is running. Open App.tsx (or your config file) and make sure the API URL points to your backend (e.g., http://localhost:3000).

 3. **Start the Frontend:**
 npm run dev   

 **Key Features**
AI Trigger: A simple button to call the backend and start the AI summarization process.
Real-time Dashboard: Displays summaries in clean, organized cards.
Delete Functionality: Remove unwanted summaries directly from the UI.
Responsive Design: Works on desktops and mobile devices.

**Tech Stack**
React.js - Frontend Framework
Custom CSS - For clean and minimal styling
Fetch API - For seamless backend communication

**Project Structure**
/src/App.tsx - Main dashboard logic and state management
/src/index.css - Custom styles for the user interface
